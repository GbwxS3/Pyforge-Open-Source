# Pyforge-Open-Source

This is an open-source project called PyForge—a programming application I created. I’ve also added support for other programming languages, though that feature isn’t fully complete yet. The primary focus of the application, however, is to make Python easier to learn and use for beginners; that’s why it includes features like a "designer" and a dedicated section for functions. I would also appreciate any feedback you might have—this is the BETA version of the application, and it is currently undergoing testing.
